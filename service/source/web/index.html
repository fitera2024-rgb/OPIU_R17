Пустые дочерние строки Инталев из результата R005

Отметьте одну или несколько фактически найденных строк выбранного родителя. Свободный ввод и автоматическая подстановка запрещены.

Сначала выберите точного родителя Инталев из результата R005.

Настройка меняет только классификацию отчёта. Проводка не создаётся.

Настроенные соответствия

Соответствий пока нет

UPDATE_MAPPING / БЕЗ ПРОВОДКИ. Привязка только переносит известную пустую строку Инталев в выбранную статью ERP для сверки. Она не доказывает физический источник, не создаёт STORNO/REPOST и не разрешает загрузку в 1С.
