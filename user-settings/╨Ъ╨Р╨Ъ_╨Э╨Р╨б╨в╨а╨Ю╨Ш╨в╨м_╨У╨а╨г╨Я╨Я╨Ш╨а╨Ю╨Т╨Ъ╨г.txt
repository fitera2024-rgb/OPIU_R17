НАСТРОЙКА ГРУППИРОВКИ ВЕРХНИХ БЛОКОВ

Файл «Настройка_группировки_блоков.csv» можно открыть и сохранить в Excel.
Кодировка файла — UTF-8, разделитель — точка с запятой.

Одна строка задаёт одну контрольную группу для одной организации:

1. «Организация» — точное название организации, выбранное при сверке.
2. «Название группы» — понятное пользователю название контроля.
3. «Коды верхних блоков» — не менее двух кодов через запятую.
4. «Активна» — «Да» или «Нет».

Для одной организации можно добавить несколько строк с разными группами.
Один код нельзя включать в две активные группы одной организации.

Правило расчёта:

- ожидаемая сумма дельт кодов одной группы равна нулю;
- если сумма равна нулю, корни показываются как закрытый структурный пересорт,
  финансовая проводка по корням не создаётся;
- если сумма не равна нулю, остаток остаётся открытым межгрупповым пересортом;
- дочерние статьи всегда продолжают обычную проверку;
- настройка одной организации не применяется к другой;
- пустой файл без строк настройки не ограничивает проверку остальных групп.

Настройка не определяет физическую организацию ERP и не заполняет неизвестные
поля проводки. Режим остаётся REPORT_ONLY; запись в 1С отключена.
