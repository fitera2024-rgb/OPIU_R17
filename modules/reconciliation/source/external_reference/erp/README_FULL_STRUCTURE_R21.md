# Полная структура ERP для сверки ОПИУ

- `ERP_Показатели_ОПИУ.xlsx` — закреплённый справочник показателей ERP; роль `erp_structure` в контрольном manifest.
- `ERP_Формулы_ОПИУ.xlsx` — закреплённые формулы строк ОПИУ; роль `erp_formula` в контрольном manifest.
- `ERP_Аналитики_ОПИУ.xlsx` — пользовательская расшифровка аналитик строк ERP.

Для фактической сверки суммы и вложенные статьи берутся из выбранной выгрузки ERP. Эти справочники подтверждают состав показателей и формул, но не подменяют живую структуру входного отчёта и не создают полномочия на проводки.

Строка `Расходы по основной деятельности ИТОГО` по закреплённой формуле включает административные расходы, коммерческие расходы, транспортную логистику и складскую логистику. Ветка, отсутствующая в старом шаблоне R001–R065, добавляется в лист сверки непосредственно из фактических деревьев Инталев и ERP как `REPORT_ONLY`.
